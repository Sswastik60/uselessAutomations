Under The Hood

More than launching apps.

A low-level automation engine built directly on Windows 11 system primitives.

🚀

Process Orchestration

Launch executables, shortcuts (.lnk), or background services. Includes process.wait_for timeouts to ensure heavy DAW/game engines initialize before firing subsequent actions.

process.launch • process.wait_for
🔊

WASAPI Audio Routing

Direct integration with Windows Core Audio APIs (WASAPI). Switch playback and recording default devices, adjust master volume, or mute outputs instantly without opening Windows Settings.

audio.set_device • audio.set_volume
🪟

Window Management

Focus-stealing bypass using AttachThreadInput and SetForegroundWindow. Minimize all background windows (Win+M), bring apps to the foreground, or toggle dedicated F11 fullscreen.

window.focus • window.fullscreen
⌨️

Hardware Scan Code Synthesis

Keystroke injection maps virtual keys to physical hardware scan codes via MapVirtualKey. Works seamlessly inside Chromium browsers, games, and DAWs that ignore standard virtual inputs.

keyboard.shortcut • keyboard.type
🌐

Browser Fullscreen Action

One-click URL launching directly in your default browser, with automated delay and optional F11 full-screen toggle for distraction-free video playback or web monitoring.

browser.open_url
⚡

Native Win32 Hotkey Thread

Zero-latency global shortcuts registered with RegisterHotKey. Runs on a dedicated background message loop that catches hotkeys even when the main window is closed to the system tray.

app.windows.hotkeys
